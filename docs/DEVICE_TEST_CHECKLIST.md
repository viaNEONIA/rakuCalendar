## 基本操作

- [ ] ページを開き、初回表示でエラーなく日表示が描画される。
- [ ] 予定を作成・編集・削除し、再読み込み後も残る。
- [ ] 予定カード上またはカードのすぐ近くから指でゆっくり/素早く上下スクロールしても、予定が動かず編集画面も開かない。
- [ ] 予定カードを長押ししてからドラッグし、スクロール操作と誤認されず、移動中に元の時刻と移動後の時刻が区別できる。
- [ ] 指を離すと予定が保存され、開始・終了時刻が15分単位に合う。移動後の所要時間が維持される。
- [ ] ドラッグで他の予定へ近づけると、前後の空き時間境界へ吸着し、意図しない重なりが生じない。
- [ ] 画面端近くへのドラッグでもスクロールと操作が両立する。
- [ ] 操作後に元に戻す / やり直すが正しい予定だけに適用される。
- [ ] 2件が重なる予定を作り、両方の内容が読めて個別に選択できる。
- [ ] 3件以上の重複でも操作対象を判別して個別編集できる。
- [ ] 閲覧モードではカードをタップすると詳細だけが開き、予定変更はできない。
- [ ] 編集モードで予定を1回タップすると選択状態になり、画面左下に上下ボタンが表示される。
- [ ] 上下ボタンで予定全体が15分単位に移動し、隣の予定に吸着して重なりを避ける。
- [ ] 選択中の予定をダブルタップすると内容編集画面が開く。
- [ ] 予定を長押ししてからドラッグすると時刻が変わり、短いタップではドラッグや編集画面が起動しない。
- [ ] 閲覧モードへ戻すと追加・編集操作が無効になり、予定カード上のスクロールが安定する。
- [ ] 数値の時・分欄と日付欄で編集・新規登録でき、分は新規時15分刻みで入力できる。
- [ ] 新規予定の初期値は15分単位で、終了時刻は開始の30分後になる。
- [ ] 追加ボタンから予定を作ると、次の予定の後に30分以上の空きがある位置へ開始時刻が設定される。
- [ ] 予定の時刻を編集画面に直接入力すると、他の予定と重なる時刻も登録できる。
- [ ] 色パレットの8色が淡く表示され、選択色がカードにも反映される。
- [ ] ドラッグで15分単位に調整した予定も、編集画面で内容を変更して保存できる。
- [ ] 現在時刻ラインと「次の予定」表示が実時刻に追従する。
- [ ] 「次の予定がある日へ」ボタンで、次に予定がある日へ移動する。翌日と翌々日以降の両方を確認する。

## PWA・データ保全

- [ ] ブラウザの「ホーム画面に追加」でインストールでき、起動URLがリポジトリ内のパスになる。
- [ ] JSONバックアップを書き出し、別のブラウザプロファイルまたは端末で統合復元できる。
- [ ] 同じバックアップを再度統合しても予定が重複して増えない。
- [ ] 不正JSON / 未対応形式を拒否し、既存予定が残る。
- [ ] 一度オンラインで開いた後、機内モードで再起動してアプリシェルが開く。
- [ ] オフライン中の予定編集が保存され、オンライン復帰後も維持される。
- [ ] ICSを書き出し、利用予定のカレンダーアプリに取り込んだ日時・タイトルを確認する。
